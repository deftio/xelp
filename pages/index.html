xelp

A C language command line interpreter and script parser for embedded systems.

xelp is a combined command line interpreter and script interpreter for embedded projects that run “on the metal” or may not have a formal OS. It provides a script interpreter available for debugging with the syntax of a command line. xelp works seamlessly with C and C++ so that the programmer can add their own commands, available at run time from the xelp environment. The parser requires no dynamic memory, making it safe for interrupts and memory-constrained environments.

  • Pure C (C89/C90/C99 compliant), optional C++ extern "C" support
  • Compiled sizes: 900 bytes – 4 KB depending on features enabled
  • No malloc, no globals — all state in an instance struct
  • Multiple independent instances on different serial ports
  • Char-at-a-time parsing — feed from UART, BLE, or any byte stream
  • Zero dependencies (no stdio.h, string.h, etc.)

Modes

CLICommand line with prompt, backspace, command dispatchXELP_ENABLE_CLI

THRPass-through to another peripheral (modem, debug port)XELP_ENABLE_THR

Quick start

Include xelp.h and xelp.c in your project. Configure options in xelpcfg.h:

#include "xelp.h"

XELP myXelp;
XELPInit(&myXelp, "My System");
XELP_SET_FN_OUT(myXelp, &myPutChar);
XELP_SET_FN_CLI(myXelp, myCommands);

/* Feed characters one at a time */
XELPParseKey(&myXelp, received_char);
